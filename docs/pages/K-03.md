# K-03 · Plan timeline

## Purpose

The plan as its dependency graph. Phases 0..4 are column groups, tasks are nodes in topological order, `depends_on` are arrows. **Tasks are bound by dependencies, not calendar days** - there is deliberately no date axis, so the only "length" the page reports is the critical path: the longest chain of dependencies (8 tasks today: T01 -> T02 -> T04 -> T06 -> T10 -> T20 -> T45 -> T46).

## Rules

- `R-K01` / `R-K04` - edges from a done task are drawn in the done hue, so an open dependency is visible as a neutral arrow; ready tasks carry a dot.
- `R-K02` - the model is printed inside every node in its own colour.

## Logic

- Layout: column = phase; inside a phase, a same-phase dependency pushes a task into the next sub-column (so every arrow points right); rows follow the topological order, one row per task per sub-column.
- Critical path = longest chain of `depends_on` (count of tasks, never days), memoised, cycle-safe.
- Focus: click, Enter or Space on a node, the focus Select, `?focus=<id>` in the URL, or the `plan.focusTask` action. The focused node, everything transitively upstream (dashed, doing hue) and everything downstream (accent) stay lit; the rest drop to 22 % opacity. Escape clears.
- Keyboard: every node is `role="button"` with `tabIndex=0`, tab order runs phase by phase; `+` / `-` zoom, `0` resets, Escape clears focus. Nothing is hover-only or drag-only (P-03).
- Zoom sets the SVG's width / height against a fixed `viewBox`, so text stays crisp. The graph scrolls horizontally **inside `.pl-graph-scroll` only** - the page never scrolls sideways.

## Components

Card, Badge, Chip, Button, IconButton, Select, Stat, Tooltip. The graph itself is inline SVG (a chart, not a hand-rolled control).

## Real vs mock

All real. Presence / concurrent editing on the same graph is T48.

## Responsive check (P-01)

Checked at 360, 390, 768, 1280, 1920, 2560, 3840. The graph keeps its geometry and gains a horizontal scrollbar inside its frame at narrow widths; zoom out to 40 % fits the whole plan on a phone, zoom in to 200 % for a 4K TV at 10 feet. The focus Card drops to one column under 760 px.
