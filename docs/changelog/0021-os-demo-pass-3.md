## New and changed contracts

- New action on every C- page: `demo.shareView` (`label` "Share this view", intent "copy the link to this view", permission `demo.open`); the handler returns the URL, so the WebMCP / voice caller gets the link back.
- New tracking meta: `cta_click { cta: 'share_view', role, section }` on C-01..C-07.
- No route, schema, seed or provider change. Role slugs and the `/role/:slug` contract (D-037) are untouched, which is what the landing worker's per-role links depend on.
- `src/modules/os-demo/useDemoScale.ts` is module-local on purpose; if a second module needs it, promote it into `src/a11y` next to `useViewportAtLeast`.

## Requests to foundation

1. **`Avatar` does not scale.** `.avatar` is `36px`, `.avatar-sm` is `28px` with a hard `font-size: 12px`. On a 4K TV every avatar in the demo (comms list, settings table, departments, life) stays 28 px with 12 px initials next to 36 px body text - the only sub-15 px text left in the demo at >= 1920 (measured). Please make the three sizes and the `sm` font size `calc(px * var(--scale))` / a token.
2. **`Button`'s icon is a fixed px size** (16 / 18 from the `size` prop), so a `sm` button's icon is 16 px at 360 and 16 px at 3840. Either derive it from `--scale` or accept an `iconSize` prop. Same pattern in `Chip` (44 px fixed height) and `Badge`.
3. **`Icon` could take the band itself.** Every module now needs a hook to grow a glyph. An `Icon` that multiplies its `size` by `--scale` internally (or accepts `size="sm|md|lg"`) would delete `useDemoScale()` here and the same workaround elsewhere.
4. **`Tabs` overflows the viewport at 360** the same way the calendar did: on C-04 `button.tab` sits at x = 461 inside the tab strip's horizontal scroller. Not the demo's file to fix; the fix is probably the same (wrap or stack under the phone breakpoint).
5. **`Placeholder` has no `className`**, so a wrapped control cannot be given a flex basis by its host; the C-04 composer targets `.placeholder.is-block` instead. A `className` passthrough would be cleaner.
6. Still open from pass 1: `Select` has no `optgroup` (role groups are prefixed into the label, which reads poorly at 10 feet), and the people switcher is still module-local.
