## Logic

- flattens spec.actions across routes
- live = registered on the actions bus (open the page first)
- one WebMCP tool per unique action id: `name = id`, `description = intent + label + pages + permission`, `inputSchema` from `params`, `execute` = `can()` -> validate -> open the host page if the handler is not mounted -> `run()` -> `{ ok, message, data?, deduped? }`; the same call within 1.5 s is deduplicated
- "Run" goes through the same `runAction` the CLI (`scripts/actions.mjs`), Playwright and the voice controller use, so the page cannot drift from the surface it documents
- `docs/reference/actions-manifest.json` and `docs/reference/voice-vocabulary.json` are `npm run actions -- export`; `docs/reference/control.md` is the model
