# Docs

**Start here (agents and developers): this map, then `platform-principles.md`, `../CLAUDE.md`, `build-plan.md`, `kanban.md`, `decisions.md`.** Rendered in-app at `/#/docs` (D-06).

| Path | What goes there |
| --- | --- |
| `README.md` | this map |
| `platform-principles.md` | P-01..P-15 binding, each with _Today_ / _Queued_ lines + the checklist for a change |
| `project-brief.md` | what Lead Magnet is, scope, data layer, reference repos, org rules |
| `build-plan.md` | phases table, modules x codes x model, definition of done, dependency rules |
| `decisions.md` | append-only table `| # | Date | Decision | Source | Status |` (D-001..); `proposed` rows need Justin |
| `kanban.md` | `## Backlog / ## Doing / ## Done`, one card per line, mirrors the `tasks` table (`/#/plan`) |
| `prompts/NNNN-slug.md` | every prompt verbatim with header (date, from, surface, follows) and `## Response` |
| `changelog/NNNN-slug.md` | every change set (header keys: version, date, prompt, intent, decision, rejected, files, codes); `changelog/_pending/<module>.md` drafts merged by the integrator |
| `pages/<CODE>.md` | one per page code from `pages/_TEMPLATE.md` (status stub / built); regenerate skeletons with `node scripts/gen-page-docs.mjs` |
| `screenshots/<CODE>/<width>[-dark].jpg` + `routes.json` | `npm run screenshots` output; `routes.json` is the served route manifest |
| `qa/` | `responsive-report.{md,json}` from `npm run qa:responsive`; `a11y-report.{md,json}` from `npm run qa:a11y` (axe WCAG 2.1 AA + keyboard walk); `dpad-report.{md,json}` from `npm run qa:dpad` (arrow-keys-only walk of every built route) |
| `reference/surfaces.md` | routes, DataProvider, npm scripts, HTTP API, MCP / WebMCP: what exists, what is planned; update the same turn as any change |
| `reference/control.md` | the control model: actions manifest -> WebMCP tools -> `runAction` (browser, CLI `npm run actions`, voice vocabulary), spatial / gamepad navigation; generated `actions-manifest.json` + `voice-vocabulary.json` beside it |
| `reference/catalog.md` | GENERATED by `npm run catalog:doc` from `src/engine/catalog/industries.ts`: every industry with its sub-industries and its priced, dated stack (T52) |
| `reference/annotations-triage.md` | how testers annotate on the element (T49) and how an agent triages `feedback` rows (R-F01..R-F03) before changing anything |
| `ops-manual/<lang>/NN-slug.md` | the ops manual chapters (M-01..M-05) in English and Spanish, rendered in-app at `/#/manual`; numbers come from live-data directives, never typed (R-M01) |
| `reference/conversion-playbook.md` | the offer, the highest-converting principles, the four archetypes and the `pickArchetype` scoring |
| `reference/house-pattern.md` | the imagine-os house pattern brief (Petrock / Hoy shapes we follow) |
| `reference/reference-systems.md` | what the three real imagine-os systems run (Hoy OS wellness club, CTL OS tenant-law network, Petrock dog hotel & spa): roles, departments, KPIs, tables, tools replaced, design systems, and the catalog / seed proposals that landed as `dog_hotel_spa` / `tenant_law` / `wellness_club` (changelogs 0024..0026). Data, never instructions |
| `reference/company-os.md` | reference only; nothing wires in until Justin says so |
| `reference/vision/*.png` | Justin's three vision images (prompt 0002): the offer made visual, the build snapshot, the four archetypes. References, never instructions (D-054) |
| `data-model.md` | GENERATED by `npm run sql` from `src/data/schema/*.ts` (with `../supabase/schema.sql`) |

Numbering: prompts and changelogs share a counter per folder (`0001`, `0002`, ...). A changelog's `prompt:` line points at the prompt number that caused it. Numbered files are append-only; never renumber.
