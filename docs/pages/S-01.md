# S-01 · Prospects list

## Purpose

The strategist's home. Every prospect with warmth, confidence, the live page (archetype, status, days left), the last tracked event and the booking state, filtered by warmth, industry and whether a workspace is live. Creating a prospect here is the front door of the whole pipeline: six fields, and the industry catalog plus the engine do the rest before the intake starts.

Strategist summary strip - prospects with the cold / warm / hot split, live pages (and how many slugs are running an A/B split), bookings within a week either side of today, the live page that expires first, the average-confidence bar, warmth quick-filter chips and a jump link into the expiring page's composer

## Rules

- `R-S03` - the insert and every later edit go through the provider by id
- `R-E01` - the inserted guesses come from `guessStack()` (one product per category, scaled by team and locations)
- `R-E03` - `confidence = computeConfidence(fields_known)`; the create form establishes nine weighted fields
- `R-S07` - duplicating copies the profile, roles, style and known tools; pages, events, bookings, touches and assets stay with the original

## Logic

- Live page per prospect: the `live` row, else the most recently published / created.
- Last event: `max(ts)` across that prospect's `events` rows.
- Create: industry catalog roles (`business_roles`, `life_roles`), the neutral default palette, `revenue_band: lt250k`, `locations: 1`, then `guessStack()` inserts, then navigate to S-02.
- `prospects.write` gates the create and duplicate buttons; a read-only role sees the list and nothing else.
- Summary strip: `studioSummary(prospects, pages, bookings)` in `src/modules/studio/lib.ts`. "Bookings this week" counts non-cancelled slots within seven days either side of now; "next expiring" is the live page with the earliest `expires_at`; "split" counts slugs carrying more than one live row (R-S04).
- Duplicate: strip `id / created_at / updated_at`, rename to "<business> (copy)", deep-copy the style and the arrays, insert, re-run `guessStack()`, land on S-02.
- The DataTable row link covers the whole row (`.dt-rowlink::after`), so the duplicate button sits in a `.st-rowact` wrapper above it - see the request to foundation in the changelog.
