# S-02 · Prospect profile + AI intake

## Purpose

Everything we know about one prospect, and the adaptive intake that closes the gaps. `nextQuestions()` renders as real fields, `applyAnswer()` saves each one, and the confidence meter plus the recommended archetype recompute on every answer. The stack guesses are confirmed or rejected here, and the roles and brand style that theme every prospect surface are edited here.

## Rules

- `R-S03` - every write is `update('prospects' | 'stack_guesses', id, patch)`
- `R-E03` - confidence is the weighted share of known fields; the intake asks the heaviest unknown first
- `R-E01` - the guesses being confirmed / rejected come from `guessStack()`; `savings()` ignores rejected rows

## Logic

- Control per question type: select for `industry / warmth / lang / revenue_band`, number for `team_size / locations`, comma list for `known_tools / business_roles / life_roles`, read-only summary plus "mark as known" for `style`, text otherwise.
- Saving: `applyAnswer(p, field, value)` (pure) then one `update` with the field, `fields_known` and `confidence`.
- `pickArchetype(p, { guessedTools })` re-ranks on every change; its top row is the recommendation.
- The mini preview sets `prospectStyle(palette, font)` on its root and only reads `--lp-*`; the platform tokens never fork (P-12).
- "Enrich with AI" is a `Placeholder` (T43). "Fill obvious gaps" runs `defaultEnricher` (the rule enricher) and marks the filled fields known.
