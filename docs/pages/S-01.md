# S-01 · Prospects list

## Purpose

The strategist's home. Every prospect with warmth, confidence, the live page (archetype, status, days left), the last tracked event and the booking state, filtered by warmth, industry and whether a workspace is live. Creating a prospect here is the front door of the whole pipeline: six fields, and the industry catalog plus the engine do the rest before the intake starts.

## Data

| Table | Read / write | Notes |
| --- | --- | --- |
| `prospects` | read / write | list + insert on create |
| `pages` | read | live page per prospect (live wins, else latest published) |
| `events` | read | last event timestamp per prospect |
| `bookings` | read | latest booking per prospect |
| `stack_guesses` | write | `guessStack()` rows inserted right after the prospect |

## Rules

- `R-S03` - the insert and every later edit go through the provider by id
- `R-E01` - the inserted guesses come from `guessStack()` (one product per category, scaled by team and locations)
- `R-E03` - `confidence = computeConfidence(fields_known)`; the create form establishes nine weighted fields

## Logic

- Live page per prospect: the `live` row, else the most recently published / created.
- Last event: `max(ts)` across that prospect's `events` rows.
- Create: industry catalog roles (`business_roles`, `life_roles`), the neutral default palette, `revenue_band: lt250k`, `locations: 1`, then `guessStack()` inserts, then navigate to S-02.
- `prospects.write` gates the create button; a read-only role sees the list and nothing else.
